# Bit Plane Slicing

This project performs Bit Plane Slicing on a grayscale image.

## Description

The program extracts all 8 bit planes of the image and displays them along with the original image.

## Requirements

* Python
* OpenCV
* NumPy
* Matplotlib

## Input

`nature.jpg`

## Output

The output contains the original image and Bit Plane 0 to Bit Plane 7.

Output file:

`output/bit_plane_result.png`
